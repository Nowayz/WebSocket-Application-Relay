# Reject malformed missing-variable replies — 2026-10-19

The bridge previously accepted an upstream reply `[0, [200, [false, value]]]` with any valid CBOR value and silently emitted an empty legacy variable result. The [command contract](../../protocol.md#commands) requires `[false, null]` for a missing variable. This could hide a malformed upstream reply as an ordinary missing key.

The selected change consumes and validates the null field before producing that result. It adds one decoder operation, with no new state, queue, API, allocation strategy or protocol limit. Present byte/text values, including empty values and UTF-8, retain their legacy encoding. Present structured/null values still require a native CBOR client. Native forwarding and source FIFO are unchanged. This is a validation fix, with no performance claim.

The focused regression fails against the old conversion path. It verifies valid missing-null output, seven non-null missing payloads (booleans, integer, bytes, text, array and map), four present byte/text values including empty and UTF-8, and the existing unsupported present-null rule. All 123 library tests pass in 0.53 seconds, warnings-denied bins/lib/test-target Clippy passes, and all 65 JavaScript protocol/legacy/idle checks pass in about 1.12 seconds with six checked resource gauges retired.

A separate controlled upstream performs real WebSocket upgrades, receives the exact CBOR subscription and variable-read request, and sends either `[false, false]` or `[false, null]` to a disposable release bridge. The historical control binary converts both to the nine-byte empty legacy result. The selected frozen release bridge converts only the valid null case; the malformed case uses its existing unsupported-reply Close path: 1003 / `Value Requires CBOR Client`. No new Close-code policy is introduced. Each frontend completes its Close/EOF exchange, the upstream retires, and the bridge descriptor count returns from 10 to 10. All four case processes exit zero without forced termination and all controller threads finish.

The control is the frozen `bridge-prebind-limits-20261019-selected` artifact, which predates unrelated channel-list work as well as this fix. This is a behavior comparison, not a matched performance benchmark. The failing current-source unit regression isolates the missing-null validation independently. Both executable hashes and complete commands are retained. The selected release build uses a fresh source-only snapshot and records `fresh:false` and exact input hashes; the working source matches its manifest. Existing manual services, convenience binaries and unrelated dirty source files were preserved.
