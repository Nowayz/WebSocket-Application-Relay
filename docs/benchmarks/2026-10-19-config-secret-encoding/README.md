# Reject malformed secret encodings instead of treating them as absent

Selected: Config::load_secrets returns Result<()> and distinguishes an absent environment variable from a non-UTF-8 value. Missing or empty WAR_AUTH_PASSWORD/WAR_ADMIN_TOKEN retains the existing None behavior. Valid UTF-8 values are loaded unchanged and then pass through the existing length/policy validation. Encoding errors name the variable only; the invalid OsString is never formatted. Both reads complete before either existing field is replaced, so an error leaves both config fields intact.

The executable propagates this result before validate, logging setup, listener binding or worker startup. Rust embedders that load these environment settings should now call config.load_secrets()? and then config.validate()?. This is an intentional fallible API change; callers must handle or propagate the returned error. Directly constructed Config secret fields remain available as before. No data-plane path, allocation policy, quota, locking, FIFO or payload-sharing change is made.

Previously env::var(...).ok() converted NotUnicode into the same state as NotPresent. An invalid authentication password silently disabled privileged relay authentication. An invalid admin token silently became None: mutation/listing requests still could not authenticate, but loopback metrics became public under the existing no-token metrics rule. A non-loopback admin listener still had its separate token-required validation; this report does not claim unauthenticated management writes.

A Unix integration test launches the actual Cargo-built native binary with child-only byte environments, avoiding unsafe global environment mutation. A held TCP listener occupies the requested relay address. If secret loading succeeds, an ordinary bind error ends the child immediately; malformed secrets must instead fail with their variable name and UTF-8 error before that bind. A two-second failure guard kills/reaps a child that does not exit. A synthetic secret prefix must never appear in diagnostics. The original implementation fails the malformed-encoding regression; selected code passes both variable cases. Another test confirms absent, empty, ASCII and Unicode values still pass loading/configuration and reach the deliberate bind error. These checks are startup validation, not a claim about every Unicode token's HTTP transport representation.

All 114 clean library tests pass in 0.48 seconds and both integration test methods (six child cases) pass in 0.02 seconds. Strict bins/library/test Clippy passes. The clean snapshot excludes the three pre-existing dirty Rust/C++ overlays.

An independent Unix release probe uses synthetic malformed byte values and disposable loopback endpoints. The frozen original executable starts for both malformed variables and unauthenticated loopback metrics returns 200; each old fixture is then stopped cleanly. The newly frozen selected executable exits 1 for each variable with exactly a redacted configuration diagnostic and no listener-start log. The admin-token case directly confirms the old ignored-token behavior; no live user data or production service is involved. All four release cases pass and are recorded with exact commands and binary hashes.

The supported clean-snapshot JavaScript checker passes all 65 native/CBOR/original relay.js/legacy/idle tests in 1.121 seconds, with no skips and all six checked resource gauges zero. Build/install/startup add wall time. Existing manual services and convenience executables are not replaced. No ordinary performance or large-population test is warranted for this startup-only correction.

Original/selected source, patch, integration test, before/after logs, release probe/receipt and frozen build manifest are retained. Run python verify.py for the saved-evidence check. Run cargo test --test config_secrets in the intended source tree for the bounded Unix regression; use a clean snapshot to exclude local prototypes. The archived release probe uses repository-local frozen paths and a fresh output guard; select new output paths before repeating it. No actual credential values are included in this evidence.
