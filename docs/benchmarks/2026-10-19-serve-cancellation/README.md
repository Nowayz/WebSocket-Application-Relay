It confirms both connections and a live admission entry/read reservation before aborting the serve task. The containing JoinSet also aborts the service on an early test failure. All waits, setup, and listener checks share an outer three-second deadline; progress waits yield instead of sleeping.

With both client descriptors still alive, it checks that the relay enters draining, all native connections/slots and read reservations retire, the per-IP admission index becomes empty, sessions return to zero with only the global channel remaining, and queued/output-capacity bytes are zero. SO_REUSEADDR permits reuse despite unrelated TCP TIME_WAIT state; a surviving listener must still prevent the replacement bind. Asynchronous listener retirement is awaited within the same deadline.
