# Retire inspection children after a profiler ignores SIGINT

Selected: inspection.py uses one private profiler-stop routine at measured-phase completion and exceptional cleanup. It sends SIGINT if the profiler is running, waits the existing ten-second grace period, then kills and waits up to five seconds to reap a profiler that did not respond. Both call sites record perf_exit_code and perf_forced_kill. A forced stop cannot pass the run. Successful stop accepts the existing zero or SIGINT exit codes.

Previously a TimeoutExpired from perf.wait inside finally escaped before client kill, server shutdown, log capture and receipt writing. A normal measured-phase timeout could therefore be followed by another failing ten-second cleanup wait. The new routine handles that SIGINT-timeout case once, then continues the existing child cleanup. It preserves an earlier workload error rather than replacing it with the cleanup status. Server/client shutdown policies, workload validation and ordinary timing gates are unchanged; no generic process supervisor or public setting is added.

A bounded unit regression controls server/client/profiler objects and raises the wait timeout immediately, without wall-clock sleeping or OS children. It covers timeout at ordinary measured completion and timeout during cleanup of an earlier workload error. Both cases fail against the original runner at the unhandled finally timeout. Selected cases verify one grace wait plus one bounded reap, profiler/client kill, server termination, closed client pipes, captured profiler output, the original workload error when present, and exact JSON receipt persistence. The one test method has two subcases and passes in 0.003 seconds. Eight existing receipt/preflight methods also pass in 0.746 seconds.

A separate real-child probe runs a frozen native relay and real inspection client for one traffic second. Its controlled perf executable ignores SIGINT. A Popen subclass shortens only that profiler's ten-second grace wait to 0.05 seconds for this failure injection; production deadlines are not changed. The runner kills/reaps the controlled profiler and blocked load client (both -9), gracefully stops the relay (0), returns CLI status 1, and writes a failed receipt with perf_forced_kill=true and the captured profiler output. Every tracked child is terminal before the probe's fallback cleanup; fallback_killed_pids is empty. A short platform utility used during host discovery also exits normally. This demonstrates actual process retirement after the controlled SIGINT refusal, not arbitrary kernel/process failure behavior.

A separate one-second fixture uses real perf record. It completes full payload/FIFO/counter/Close/retirement checks, accepts profiler exit -2 (SIGINT), records perf_forced_kill=false, and exits both native/client children zero. All six checked final resource gauges are zero. The raw perf.data remains at its SHA-pinned local artifact path. Both fixtures are explicitly profile_diagnostic; their CPU/latency values are excluded from ordinary performance results. Build/setup and checked teardown add wall time.
